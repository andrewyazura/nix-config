Vault

A personal assistant for one person's calendar.

Vault is a private tool built and run by Andrew Yazura. It reads and writes the Google Calendar of its sole user — the same person who runs it — so that he can review, plan and schedule from his own notes and chat interface instead of the calendar UI.

What it does

  • Reads calendar events, so it can answer questions about the day.
  • Creates, edits and deletes events when its user asks it to.

Who it is for

Only its owner. Vault is not a product, has no sign-up, and has no users other than the single Google account that authorises it. It is published to Google solely so that the OAuth authorisation it uses does not expire every few days.
