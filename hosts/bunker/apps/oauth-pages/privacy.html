Privacy policy

Vault — a personal calendar assistant.

Vault is a single-user personal tool built and run by Andrew Yazura. It has exactly one user: the owner. There is no sign-up, no account system and no other person whose data it could hold.

What it accesses

Vault accesses only the Google Calendar of the Google account that authorises it. Within that calendar it reads and writes event data:

  • Event titles, descriptions and locations.
  • Start and end times, time zones and recurrence.
  • Attendees listed on the owner's own events.

It accesses nothing else in the Google account — no mail, no files, no contacts, no other Google service.

Why it accesses it

Reading events lets the assistant answer the owner's questions about his schedule and plan around it. Writing events lets it create, change and delete entries when the owner asks it to. There is no other purpose.

Where the data goes

  • Calendar data is fetched from Google's Calendar API and used to answer the owner's requests on hardware the owner controls.
  • The OAuth credentials and any cached calendar data are stored on that same hardware, readable only by the owner.
  • Nothing is sold. Nothing is shared with any other person or company. Nothing is transferred to a third party beyond Google's own API, which is the source of the data in the first place.
  • There is no analytics, no tracking, no advertising and no third-party script on this website — these pages are static HTML and set no cookies.

Retention and deletion

Cached calendar data is kept only as long as it is useful to the owner and can be deleted by him at any time. The owner can revoke Vault's access at any time from the Google Account permissions page, which stops all further access immediately.
