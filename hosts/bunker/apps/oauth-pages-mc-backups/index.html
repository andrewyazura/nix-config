Minecraft Backups

Off-site backups for one person's Minecraft servers.

Minecraft Backups is a private tool built and run by Andrew Yazura. On a fixed schedule it archives the worlds of the Minecraft servers its owner hosts and uploads those archives to the owner's own Google Drive, so that a lost or corrupted world can be restored.

What it does

  • Creates a folder in the owner's Google Drive to hold the backups.
  • Uploads one world archive per server on every scheduled run.

It uses the drive.file permission, so it can see only the files and folders it created itself. The rest of the Drive is invisible to it.

Who it is for

Only its owner. Minecraft Backups is not a product, has no sign-up, and has no users other than the single Google account that authorises it. It is published to Google solely so that the OAuth authorisation it uses does not expire every seven days.
