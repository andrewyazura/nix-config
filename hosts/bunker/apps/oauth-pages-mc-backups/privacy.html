Privacy policy

Minecraft Backups — off-site world backups.

Minecraft Backups is a single-user personal tool built and run by Andrew Yazura. It has exactly one user: the owner. There is no sign-up, no account system and no other person whose data it could hold.

What it accesses

Minecraft Backups requests a single Google permission, drive.file, which grants access only to files and folders the app created itself. Within those files it:

  • Creates the folders that hold the backups.
  • Uploads backup archives into them.
  • Reads the names, sizes and dates of the files it uploaded, so that it does not upload the same archive twice.

It cannot list, open, change or delete any other file in the Google Drive, and it accesses no other Google service — no mail, no calendar, no contacts.

Why it accesses it

To keep an off-site copy of the owner's Minecraft server worlds, so that they can be restored after data loss. There is no other purpose.

Where the data goes

  • Backup archives are created on a server the owner controls and uploaded to the owner's own Google Drive. They contain Minecraft world files, not data taken from the Google account.
  • The OAuth credentials are stored on that same server, readable only by the backup service.
  • Nothing is sold. Nothing is shared with any other person or company. Nothing is transferred to a third party beyond Google's own Drive API, which is where the backups are stored.
  • There is no analytics, no tracking, no advertising and no third-party script on this website — these pages are static HTML and set no cookies.

Retention and deletion

Uploaded archives stay in the owner's Google Drive until the owner deletes them. Local copies on the server are deleted automatically after a configured number of days. The owner can revoke Minecraft Backups' access at any time from the Google Account permissions page, which stops all further access immediately.
